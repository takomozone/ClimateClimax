# ClimateClimax project instructions

- Append each new user-authored project request to `PROMPTS.txt` before completing the work requested in that turn.
- Preserve the user's wording. Add an ISO date when it is available.
- Record only the user's actual request. Do not include ambient browser context, environment metadata, system instructions, tool output, or assistant responses.
- Do not duplicate a prompt that is already present in the log.
